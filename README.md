# Luz Violeta 📱

Aplicativo Android feito em Java, voltado para o apoio a mulheres vítimas de violência.

## 🌟 Funcionalidades principais

- Cadastro de usuário (integração simulada com gov.br)
- Registro de denúncias com dados e localização
- Armazenamento local com SQLite
- Arquitetura MVC com controllers e banco de dados local

## 🧠 Tecnologias utilizadas

- Java
- Android Studio
- SQLite
- Git/GitHub
- XML para layouts
- Padrão MVC

## 📂 Estrutura geral

- `/model`: classes de dados (Usuário, Denúncia, Atendimento)
- `/controller`: lógica de banco e regras de negócio
- `/view`: telas do app (login, cadastro, lista de denúncias, etc.)
- `/layout`: arquivos XML com o design visual
